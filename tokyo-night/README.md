# Tokyo Night Theme

Clean theme inspired by [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme). Features a deep blue-navy dark mode with soft blue accents, and a muted day variant.

## Colors

- **Primary:** Soft blue (`#7aa2f7`)
- **Background:** Deep navy (`#1a1b26`) / Silver (`#d5d6db`)
- **Accent:** Muted indigo (`#292e42`)
- **Destructive:** Coral pink (`#f7768e`)

## Installation

```bash
zip -r tokyo-night.zip manifest.json theme.css
```

Upload `tokyo-night.zip` via Admin → Themes in Bulwark Mail.
