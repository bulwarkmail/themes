# Rosé Pine Theme

Elegant theme inspired by [Rosé Pine](https://rosepinetheme.com). Features natural, muted colors with warm rosy accents for a comfortable reading experience.

## Colors

- **Primary:** Rose (`#ebbcba`)
- **Background:** Deep plum (`#191724`) / Warm cream (`#faf4ed`)
- **Accent:** Muted purple (`#26233a`)
- **Destructive:** Love (`#eb6f92`)

## Installation

```bash
zip -r rose-pine.zip manifest.json theme.css
```

Upload `rose-pine.zip` via Admin → Themes in Bulwark Mail.
