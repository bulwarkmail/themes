# Dracula Theme

Dark theme inspired by the famous [Dracula](https://draculatheme.com) color scheme, featuring its signature purple accents and warm dark background.

## Colors

- **Primary:** Purple (`#bd93f9`)
- **Background:** Dark charcoal (`#282a36`)
- **Accent:** Subtle gray-purple (`#44475a`)
- **Destructive:** Dracula Red (`#ff5555`)

## Installation

```bash
zip -r dracula.zip manifest.json theme.css
```

Upload `dracula.zip` via Admin → Themes in Bulwark Mail.
