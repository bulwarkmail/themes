# Gruvbox Theme

Warm, retro color scheme inspired by [Gruvbox](https://github.com/morhetz/gruvbox). Features earthy tones with vibrant orange accents.

## Colors

- **Primary:** Orange (`#fe8019`)
- **Background:** Warm dark (`#282828`) / Cream (`#fbf1c7`)
- **Accent:** Warm gray (`#504945`)
- **Destructive:** Gruvbox Red (`#fb4934`)

## Installation

```bash
zip -r gruvbox.zip manifest.json theme.css
```

Upload `gruvbox.zip` via Admin → Themes in Bulwark Mail.
